统计口径

数字来自本机的会话日志，不是账单。Claude 一侧读 Claude Code 的日志，同一条响应只算一次；ChatGPT 一侧读 Codex 的日志；Gemini 一侧直读 Antigravity 本机 SQLite 数据库（含父子代理工作区穿透归属与 Protobuf 原始模型 ID）。

输入指没有命中缓存的输入；缓存写入和缓存读取单列；输出包含推理 tokens。合计是这四项之和。Codex 的日志没有缓存写入这一项。

“较前一段”拿所选范围和紧挨在它前面、同样天数的一段比；选“全部”时没有可比的前一段。

等值花费是把这些 tokens 按公开的 API 单价算出来的钱，不是你实际付的钱，订阅是固定月费。缓存写入按 5 分钟档 1.25 倍、1 小时档 2 倍输入价计；没有算长上下文加价。下表以外的模型（经中转的 glm、deepseek 等）没有计价，按 0 算。GPT 的单价来自第三方价格追踪站，不是 OpenAI 官网。
